# Global Hotkey

Jubako は以下のショートカットキーで呼び出されます。

- **Windows**: `Win + Alt + V`
- **macOS**: `⌘ + ⌥ + V`（Command + Option + V）

## ショートカットキーの競合
- 既に使われている可能性があるショートカットキーですが、本アプリではこれをグローバルホットキーとして登録します。
- 将来的には設定画面から変更可能にします。

## 呼び出し時の挙動
- マウスカーソル位置とモニタ境界・DPI スケールを考慮し、画面からはみ出さない位置にポップアップを表示します。
- 再度ホットキーを押すか、ウィンドウ外をクリックすると非表示になります。
