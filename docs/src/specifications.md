# Specifications

Jubako の主な仕様は以下の通りです。

## 基本機能
OS 標準のクリップボード履歴と同等の履歴機能を備えます。
- コピーしたテキスト、画像を自動で保存。
- 直近の履歴を一覧表示。

## 階層化永続化
履歴として保存されたアイテムを、ユーザーがフォルダ分けして永続的に保存できます。
- アイテムをドラッグ＆ドロップで階層構造（フォルダ）に移動。
- 階層化されたアイテムはアプリを再起動しても保持されます。
- 階層構造はネスト可能です。

## UI レイアウト
1. **2カラム構成**:
   * **左ペイン (Sidebar)**: 「History」および階層構造（フォルダ）を表示。新規フォルダ作成やフォルダ操作メニュー（サブフォルダ追加・リネーム・削除）を提供。
   * **右ペイン (Main)**: 選択したフォルダ内のアイテム、または「History」を一覧表示。

## ウィンドウの振る舞い
- `Win + Alt + V`（Windows） / `⌘ + ⌥ + V`（macOS）でマウスカーソル位置付近にポップアップ。
- タスクバー / Dock には表示しない（Windows はツールウィンドウ、macOS は `NSApplicationActivationPolicy::Accessory` および `.app` の `LSUIElement = true`）。
- ウィンドウ外をクリック（フォーカス喪失）した際に自動的に閉じる。
- アイテムをクリックすると、クリップボードに設定してウィンドウを閉じた上で自動ペーストを実行する。
