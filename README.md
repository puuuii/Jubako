# Jubako

Jubako は、階層フォルダとローカル SQLite 永続化を備えた Windows / macOS 向けクリップボードマネージャーです。

## 主な操作

- **ポップアップ表示**: `Win + Alt + V`（Windows） / `⌘ + ⌥ + V`（macOS）
- **貼り付け**: アイテムをクリックするとクリップボードへ設定し、直前のアプリへ自動ペースト（`Ctrl + V` / `⌘ + V`）します
